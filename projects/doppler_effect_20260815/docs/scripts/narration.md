# 教学脚本(narration)

> 分节旁白脚本,结构:先故事 → 再公式 → 最后澄清。每节带秒数预算(与 shot_table.md 对应)。
> 目标:5 节 38 句,预算合计 180 秒,字幕密度 3.5~5s/句。

## 【1. 现象:驶近变高,驶离变低】约 20 秒

1. 你有没有注意过:救护车鸣笛驶近时,笛声尖锐;驶过后,音调突然低沉。
2. 这不是错觉——1842 年,奥地利物理学家多普勒预言了这个现象,1845 年 Buys Ballot 用一列火车和号手验证了它。
3. 后来人们用他的名字命名:多普勒效应。
4. 今天我们用 3 分钟,把这个"音调变化"拆开看清楚。

## 【2. 波面图景:波长被压扁了】约 32 秒

> 类比「波源追着自己刚发出的波」的边界分析见 design_spec §VII。

1. 声音是波,波源每秒发出 f 个完整波,这些波以波速 v 在空气里传开。
2. 波源静止时,波面是一圈圈同心圆,前后波长一样,都是 λ = v/f。
3. 现在让波源向右运动:它一边发波,一边追着自己刚发出的波。
4. 前方的波面被压缩,波长变短;后方的波面被拉伸,波长变长。
5. 关键:波速 v 没有变——它由空气决定,变的只是波长。
6. 站在前面的人,每秒会收到更多个完整波,所以听到的频率更高。
7. 这就是多普勒效应的全部物理:相对运动改变了"每秒接收的波数"。

## 【3. 公式:分子分母各管一件事】约 52 秒

1. 先定义:v 是波速,f 是波源频率,观察者与波源的靠近速度分别记作 v_o 和 v_s。
2. 情况一,观察者动、波源不动:波长不变,但观察者相对波的速度变成 v+v_o。
3. 于是每秒接收的波数 f' = (v+v_o)/λ = f(1+v_o/v):驶近升高,驶离则把加号换成减号。
4. 情况二,波源动、观察者不动:一个周期 T=1/f 里,波源前进了 v_s·T。
5. 波长被压缩成 λ' = (v−v_s)/f,接收频率 f' = v/λ' = f·v/(v−v_s)。
6. 注意:两种情况的公式并不相同——一个在分子,一个在分母;只有速度远小于波速时,它们才趋同。
7. 合并成统一式:f' = f(v±v_o)/(v∓v_s),上面的号对应驶近、下面的号对应驶离。
8. 算一个数:救护车以 100 km/h ≈ 27.8 m/s 驶近,声速取 340 m/s。
9. f' = 340/(340−27.8)·f ≈ 1.089 f——频率升高约 9%,1000 赫兹的笛声变成 1089 赫兹。
10. 这 9% 耳朵听得清清楚楚,所以救护车一响,你就知道它来了。
11. 这个"频移"还能用来测量看不见的运动——比如车速和血流。

## 【4. 应用:测车速、看血流、读宇宙】约 44 秒

1. 交警的雷达发射 10.525 GHz 微波,打在车上反射回来。
2. 车在动,微波往返被频移两次:f_d = 2f₀v/c,100 km/h 的车对应约 1.95 kHz 的频差。
3. 测出频差,车速立现——这是多普勒效应最日常的应用。
4. 医院里,超声波探头发出 2~10 MHz 声波,打到流动的血细胞上。
5. 血流 0.3~1 m/s,频移几百到几千赫兹,医生由此看血流方向与速度。
6. 天文学家看的是光:恒星的光谱线整体移动,远离我们的谱线向红端移动——红移。
7. 光的频移没有介质可依托,只取决于相对速度,低速时 Δf/f ≈ v/c。
8. 高速时必须用相对论公式 f_obs = f_s√((1+β)/(1−β)),其中 β = v/c;哈勃正是靠红移发现宇宙在膨胀。
9. 从警笛到星系,同一个效应,贯穿声波与光波。

## 【5. 澄清:三个误区 + 一句话总结】约 32 秒

1. 误区一:"声源运动会改变波速"——错,波速由介质决定,声源只改变波长。
2. 误区二:"声源动和观察者动完全一样"——错,公式一个在分母、一个在分子,只有低速才趋同。
3. 误区三:"音调变化只是响度或心理错觉"——错,接收频率是实实在在变了,可以精确测量。
4. 还有一个边界:声学公式不能直接套给光,光的多普勒要走相对论。
5. 把这三个误区串起来,就是今天最值得记住的一句话。
6. 多普勒效应 = 相对运动改变了每秒接收的波数。
7. 下次听到救护车的笛声,愿你想起的,是这幅被压缩的波面。
