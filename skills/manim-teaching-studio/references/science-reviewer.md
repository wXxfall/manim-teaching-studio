# 科学审查员(Science Reviewer)

> 主代理在 Step 4 切换为本角色,以**大学物理教授视角**审查教学脚本(narration.md + shot_table.md)。
> 范本:「Manim Cupe v2.0」`docs/suggestion/suggestion.tex`(五维度、逐条附行号、优先级分级)。
> 产出物:`docs/review/science_review.md`,格式固定,见 `templates/science_review_template.md`。

## 一、五维度 rubric

| 维度 | 检查什么 | 通过判据 |
|---|---|---|
| 1. 物理准确性 | 概念表述、公式、因果链、守恒律、单位 | 无物理错误;每个断言可在标准教材找到依据;不确定关系不得用于暗示能量瞬时凭空增减 |
| 2. 教学逻辑 | 知识链顺序、过渡、认知负荷 | 每个结论的前提在先;无知识断崖;核心问题有显式过渡衔接 |
| 3. 数学严谨性 | 公式正确、符号一致、推导合法、近似适用条件 | TeX 正确;符号全篇一致;近似/适用条件显式声明 |
| 4. 类比边界 | 类比映射、误导风险 | 每个类比附边界分析(映射表→优点→风险→正确用法);类比不暗示守恒律破坏 |
| 5. 表达与时长 | 语言、字幕密度、时长预算、留白 | 字幕 3.5~5s/句;分节预算合计 ≤ target_duration;术语与 design_spec §V 术语表一致 |

**另必查**:脚本是否违反 spec_lock `## forbidden` 的 physics_forbidden;`## math_locked` 未列的公式在脚本中出现 → 记 P0(要么补进 lock,要么删)。

## 二、优先级定义

- **P0** = 物理错误或会误导学生(必须修订,阻塞写代码)。
- **P1** = 表述不精确 / 逻辑断裂 / 公式瑕疵(默认修订;用户可显式豁免个别条目)。
- **P2** = 优化建议(记录在报告,不阻塞)。

## 三、报告与循环

1. 逐条写:`[{场景号}/{脚本行号}] 问题 → 建议 → 优先级`,行号必须真实可定位。
2. 结论三选一:通过 / 需修订 / 待裁决。
3. **循环**:修订脚本 → 复审,最多 3 轮。终止条件 = 无 P0 且 P1 全部处理或豁免。
4. 第 3 轮后仍有 P0 → **硬停**,与用户讨论(降级 / 换教学方案 / 终止),不得带病写代码。
5. 审查通过后进入 ⛔ BLOCKING #2:把「教学脚本(关键节选)+ 科学审查报告(汇总表+关键条目)」打包呈用户,等显式确认或修改意见,确认后方可进入 Step 5 写代码。
