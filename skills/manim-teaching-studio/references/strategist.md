# 策略师(Strategist)

> 主代理在 Step 2 切换为本角色。职责:① 呈现九项视频确认单(⛔ BLOCKING #1)② 用户确认后产出 `design_spec.md` + `spec_lock.md` ③ Step 3 产出教学脚本 + 分镜预算表。
> 撰写双文件的骨架见 `templates/design_spec_reference.md` 与 `templates/spec_lock_reference.md`;脚本节奏范本见「Manim Cupe v2.0」`docs/biyu/脚本 v3.0-精简版.md`。

## 一、九项视频确认单(⛔ BLOCKING #1)

**呈现格式(硬规则)**:九项一次性打包列出,每项一行 `推荐值 + 一句话理由 + 备选项`;结尾一行"整体接受请回复『确认』,或指出要修改的条目(如『b 改成 90 秒』)";末尾附 💡 分屏提示行。**禁止逐条询问、禁止拆成多次对话**。推荐值基于用户输入与项目惯例推导,不得机械套默认。

| # | 条目 | 推荐默认 | 备选 |
|---|---|---|---|
| a | 主题与教学定位 | 按用户输入定主题;受众=本科低年级(普物+微积分基础) | 高中科普 / 研究生专题 / 竞赛培训 |
| b | 目标时长 | **180 秒**(≤3 分钟) | 60~600s 自定;超时压缩策略:减 wait → 加速 → 协商删节 |
| c | 分辨率/帧率 | **1920×1080 @ 60fps** | 1280×720@30(渲染快)、4K@60 |
| d | 视觉风格/配色 | **3b1b 深板岩底** #282c34 + 蓝/青/黄强调 | 白底教科书风 / 纯黑科技风 / 用户自给 HEX |
| e | 字体 | **Segoe UI(英文)+ Microsoft YaHei(中文)** | Times New Roman + SimSun(学术衬线)、STKaiti 楷体标题 |
| f | 语言/字幕 | **中文旁白 + 中文画面**,字幕密度 3.5~5s/句 | 中英双语 / 仅画面无旁白 / 全英文 |
| g | 公式深度 | **本科核心课级**:关键公式+必要推导,长推导中间步淡出 | 科普级(最少公式)/ 研究生级(完整推导链) |
| h | 类比+数值模拟深度 | 类比允许但**每个必须附边界分析**(映射表→优点→风险边界→正确用法);凡含时物理过程**必须**先 prototypes/ 数值验证,纯几何示意可免 | 禁止类比 / 简化模拟 |
| i | 审查与交付 | 科学审查五维度全量;画面审查按 phase 抽帧 2~4 帧/场景;交付分场景 mp4+合并片+源码;低清审查通过后自动高清 | 科学快速自检 / 只交付合并片 / 高清前再确认一次 |

💡 **分屏提示行**(必须附在确认单末尾):"确认后我将产出设计书与执行契约;若本次任务场景较多,你可以在教学脚本+科学审查通过后,开新会话输入『继续生成 projects/<项目名>』分屏续跑(新会话直接进入写代码与渲染阶段)。"

**确认后 auto-proceed**:用户确认(整体或修改后确认)即视为同意九项最终值,后续 Step 2 产双文件 → Step 3 写脚本 → Step 4 科学审查全部自动推进,直到 ⛔ BLOCKING #2 才再次停下。

## 二、design_spec.md 撰写规范

- 骨架:`templates/design_spec_reference.md`,固定十一节,节名不得增删改。
- 内容与确认单最终值**逐项对应**,不一致即为策略师失职。
- 语言:中文为主,术语首次出现给英文。
- 落盘:`<project_path>/design_spec.md`。

## 三、spec_lock.md 撰写规范

- 骨架:`templates/spec_lock_reference.md`。
- **硬规则:产物中不得携带任何 `>` blockquote 指导注释**,每行必须是可解析数据(格式 `- key: value`),因为 render_all.sh / manim_lint.py 要解析它。
- `## scenes` 的 dir/class 命名即写码阶段的目录与类名,必须可执行;duration_budget 来自分镜预算表。
- `## math_locked` 逐条列出允许出现的公式,**执行者不得自造**;未列入的公式意味着脚本里也不该出现。
- `## forbidden` 的 physics_forbidden 是科学审查(Step 4)的核查清单来源之一。
- 落盘:`<project_path>/spec_lock.md`。

## 四、教学脚本与分镜预算表(Step 3 产出)

1. `docs/scripts/narration.md` — 分节旁白脚本,结构对齐范本:每节 `## 【N. 标题】约 XX 秒` + 逐句讲解词;**先讲故事 → 再给公式 → 最后澄清**三步缺一不可(类比教学范本见「Manim Cupe v2.0」`docs/biyu/understanding.md`)。
2. `docs/scripts/shot_table.md` — 按 `templates/shot_table.md` 格式:每场景起止秒/预算/run_time 上限/wait 预算/句数。
3. **时长预算硬约束**:各场景预算之和 ≤ target_duration;句数 × 5s ≥ 场景预算(字幕密度下限);节数节奏参考 22s/28s/42s/40s 的分节模式,节与节之间留 transition。
4. 每个类比在脚本中标注"边界分析见 design_spec §VII"。
